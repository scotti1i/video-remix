# 按真实镜头生成，不按功能段硬拆

用户要忠实复刻多镜头原片时使用。此路线复用每镜现有 `compile/run`，用独立组装合同处理已下载片段；v1 保留既有行为，v2 增加登记素材音轨。不修改旧计划/规格格式，不强制所有视频都分段。

## 从原片决定生成单位

核对实际切点：前后视角、主体或场景的突变才是候选切镜，闪光、镜片变暗、遮挡并不自动算切镜。一镜到底里的拿起、翻转、放下保留连续，不能按“外观/卖点/推荐”拆开。同款默认保留原镜头顺序、动作幅度、有效重复和节奏；只换人/场景时保持新场景提供相同支撑和拍摄条件。

每个镜头建立一份普通制作计划，时间从本镜0开始；交接单位是这一个镜头的完整输入，而不是整片共享素材列表。直接把对应原帧、替换后本镜垫图、必要效果状态及商品辅助图关联到该计划。垫图承担本镜画面，人物/商品母图只作辅助：机位、商品面向、距离、接触或观看关系不匹配时，不能用母图加文字代替。先从本镜真实原帧保留构图，再换人和指定场景；换场景仍提供同类支撑与拍摄条件。不把全片图片塞给每个任务，也不为每镜机械凑固定张数。

切镜起点不一定是动作起点。先区分切入时已经成立的状态与镜内实际发生的变化：原片切入时已抬脚、已触碰或已持物，就从该状态继续，不把“展示/第二次指示”展开为原片没有的抬起、入画、接近、再接触。全片的重复序号不等于本镜要重新表演一次准备过程；镜尾可见的释放/移离也不能被“持续展示到结束”抹掉。把这些事实直接写进本镜动作正文，并核对画面图是否支持；这是画面内容约束，不是强制采用首帧输入模式。该项细化既有逐镜完整输入要求（2026-09-18包接触镜、鞋末次指示镜出现过此类状态→动作误写）。

共同的人物、商品、穿搭、地点保持一致，但一致身份不等于一致构图。只有逐镜核实画面关系确实相同，才可复用对应画面；不同观察方向、距离或商品状态须准备对应垫图。为节省调用不能撤掉决定展示成立的输入，再指望角色文字压过冲突的图。输入不足就明确这一镜未准备好，而不是削减它的展示。生成图片回查原始商品部件，不能让合成错误成为下一镜真源。

把本镜为什么能展示卖点写进同一计划的动作正文：触发什么、哪一区域变化、变化后看见什么、如何恢复，以及有作用的重复；让垫图可见地支持这些关系。例如滤光演示的相机贴近镜片内侧、焊点在镜片覆盖区、镜外保留亮度参照，才有起弧变暗/停弧恢复；眼镜旁边出现亮弧并不等价。机构演示则以真实部件连接与接触为基础。先确认静态关系，再描述动态过程，不用更多“自然/真实/必须”覆盖错误构图。

保存一份简短镜头清单：原片区间、生成版本ID、生成时长、最终取用区间、声音安排及本镜素材。对应原帧和图的用途放现有计划的 `provenance`，实际画面图必须进入 `inputs`、动态机制必须进入动作正文，不能只存在交接说明里。它用于制作和恢复，不需要用户逐镜审批。模型最短时长大于原镜时长时，动作安排在有效区间，额外时间只延续收尾；但文字时间点不是执行日程，须区分计划区间与产物实际完成位置。测试中若动作仍摊满文件，不能截掉恢复/翻面、变速塞回或暗改全片切点来宣称成功；保留原片并定位该镜表达或模型遵循问题。确需改变剪辑节奏时先说明与忠实复刻目标的差异。无法在本轮预算内覆盖所有镜头时如实报告，不偷偷合并相异镜头来凑请求数。

## 连续长镜头的显式续段路线

默认垫图仍是画面参考，不把所有镜头强制改成首帧。连续镜头超过单段上限、普通参考路线在接缝处重构机位时，可显式试 `generation_route: first_frame`：先下载前段，取最终实际采用切点的末帧，登记为续段唯一图片，再走同一 `compile/run`。不能拿前段未采用尾巴的最后一帧，也不能在前段未生成时假造续接状态。仍保留原镜头动作与声音目标，不把接口名当作连续性保证。

该路线不能同时送独立商品图；只有边界画面足以承担本段外观时才考虑，后续翻面所需商品事实缺失则不能为锁首帧撤掉它们。单帧不携带运动速度、遮挡变化或连续声线，检查接缝之外还须分别看动作覆盖和声音完整性。2026-09-18单次同模型组合路线探测观察到尺度跳变减小，但首帧仍有重建差异、末词仍超出取用点；不是无缝长镜头或普遍成功率证据。此段细化原有“超上限连续长镜头仍有缺口”，不改变默认多图参考路线。

## 声音不是每镜重新开口

先区分同步口播、跨镜旁白、无口播。同步口播以完整语句和实际唇形为约束，不能将另一段配音硬盖上去；一镜到底优先由同一生成任务完成。跨镜旁白作为一个连续表达单元安排，不因画面切镜重新起句。

组装支持三种明确选择：`clips` 保留每镜自带原声，但跨任务声线与语流一致性仍待验证；`continuous` 使用明确指定的一条连续音轨，画面取自分镜；`silent` 明确去声。连续音轨可来自本项目已下载生成版本，或用 v2 选择已登记的音频/视频素材，并记录真实来源。不能默认静音解决声音困难，也不能偷偷复用对标原声。已有音轨只有台词和时序仍符合本次目标才可复用；否则说明需独立声音制作及其授权，当前后端不提供配音或声纹克隆服务。`continuous` 不会自动混入片段现场声，直接指定纯旁白会将其一起替换。

目标需要旁白和现场声同时保留时，可先用本地现有音频工具预混，再走下文v2的`asset`入口；不是增加一种组装模式。按已确定的各镜取用区间原速提取新片段声音，接到同一画面时间轴，与明确来源的连续旁白混合，保存原件、取用区间、增益、命令及混合文件哈希。混合前逐镜核对音轨起点与画面取用的对应、声音实际覆盖范围；偏移或短缺须处理或披露，不能用较长旁白让最终音轨时长通过来掩盖。音量按实际素材决定，不照抄某次实验比例。先检查片段声是否混有不需要的音乐/对白，不能把未识别出的成分当纯音效；转录不能代替听辨。登记完成的混合文件后再冻结组装/直出合同，不引用尚不存在的音轨。若不能保留所需现场声，仍须披露缺口。此路径合并原“局部混音暂不支持”说明：2026-09-18真实多镜样片验证了本地预混→素材登记→v2组装，并不证明所有声轨合适或声音已获客户接受。

已选定独立旁白时，画面任务的 `sound` 明确不生成旁白，避免各镜重复开口；这是声音分工，不是让最终影片静音。完整正文和表达目标只维护在那条声音制作记录，组装指定实际落盘音轨。仍未确定声音来源时，不用静音样片或原声成片冒充新声音方案已经完成。

这使画面路线的对照可使用同一声音条件，但不证明声音问题已修复；最终仍检查动作触发与对应词句是否合拍。无口播也需要保留用户要求的音乐/现场声安排，不默认所有片段都有可拼音轨。

## 可恢复执行与组装

用现有 `compile` 分别登记计划，按已授权总预算 `run <镜头ID…>`；未完成时恢复原ID。镜头失败可在授权范围另建版本，仅替换组装清单对应项。原片、好镜头和上一版组装保持不变，不因一镜失败重生全片。

`assemble /absolute/assembly.json` 默认只读校验/预览；加 `--execute` 才原速硬切组装。示例仅解释字段：

```json
{
  "format": "video-remix-assembly.v1",
  "id": "cut-01",
  "clips": [
    {"variant": "shot-01", "in": 0, "out": 3.3},
    {"variant": "shot-02", "in": 0.2, "out": 4.4}
  ],
  "audio": {"mode": "continuous", "variant": "narration-01", "in": 0}
}
```

用真实已下载版本和实际可用区间替换示例。声音 `variant` 须在本项目；外部配音、获准保留的原声或外项目生成音轨走已有 `asset` 登记入口，不伪造运行记录。使用登记音轨时，将合同格式改为 `video-remix-assembly.v2`，并将 `audio` 替换为：

```json
{"mode": "continuous", "asset": "voice-track", "in": 0, "provenance": "填写实际音轨来源及复用安排，不冒称本次新生成"}
```

`asset` 与 `variant` 恰选一个。素材来源说明 `provenance` 必填，1–500字；后端核验登记文件与哈希，但不替作者证实说明。素材可为独立音频或视频的第一音轨；`in` 从该音轨起点计，不按视频画面起点计。对原声同步场景先核实两者是否有延迟，不自动把延迟抹掉后称同步。音轨必须覆盖全片所需区间，不补静音、不拉长。原v1仍只接生成版本，已完成记录无需迁移。

输出在 `assemblies/<id>/`，保留合同、原文件哈希/任务或素材来源、实际处理参数与结果；原 `variants/<id>/raw.mp4` 不变。新剪法或局部替换用新组装ID，失败记录不得抹掉。画幅/分辨率不同先停，不自动裁画面；统一30帧是标准重采样（可能重复/丢弃已有帧），不是运动插帧，不自动变速、加转场、字幕或调色。

新组装先把源画面重采样为30帧，再按帧裁切：源剪入点及累计输出切点四舍五入到最近帧，恰好半帧向上；每镜帧数取相邻累计切点之差，避免误差逐镜累积。预览的 `frame_grid` 列出实际取用区间、逐镜帧数和累计切点；成片须完整解码验证总帧数。声音仍按合同原秒区间裁切，不伸缩配合量化后视频，片尾时长差最多半帧。源结尾量化或实际解码不足以提供所需帧数时失败，不补尾帧。旧完成结果只验证既有证据后复用，不追认为通过新帧精度检查；要获得新校验用新组装ID。

## 验证的是完整展示，不只是接得上

先交付组装片、各段原片与实际条件。检查是否保留原镜头和动作覆盖、切点是否破坏中间过程、跨镜商品/人物是否变化，以及声音完整性。与整条生成比较时标明历史基线、共同/不同输入和声音来源；补图、换场景或声音后期同时变化属于组合路线试验，不称纯粹“分段”的单变量实验。不因局部变形少了就忽略漏展示、声音漂移或总成本增加。

该入口只做明确片段的组装，不自动发现切点、追踪人物、对齐词级时间或保证连续长镜头无缝续接。一次样片仅验证这组条件，不代表所有品类成功率已提高。
